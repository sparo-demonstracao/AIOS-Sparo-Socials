# Arquivo morto

Aqui vive o que já cumpriu seu papel: coisas antigas não se deletam — se movem pra cá. Automação aposentada, prioridade de trimestre vencido, versão substituída de qualquer arquivo.
Como usar: mova o arquivo pra esta pasta com o nome original (nunca apague) e, se quiser, deixe uma linha no `decisions/log.md` contando por que aposentou.
